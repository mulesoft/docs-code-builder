= Deploy Agent Network Instances

Deploy your agent network instance to a deployment target. You can deploy to a CloudHub 2.0 private space or to a Runtime Fabric (limited availability). When you deploy, Flex Gateway secures your agent network into the ingress gateway. Also, it secures your brokers, agents, and MCP servers into the egress gateway.

[NOTE]
====
If you run operations within a CI/CD environment, you can use Anypoint CLI's plugin to set up, create, build, publish, and deploy agent networks. For more information, see xref:af-build-agent-networks-in-a-ci-cd-environment.adoc[].
====

== Before You Begin Deploying Agent Networks

Make sure you meet the prerequisites for this task. For prerequisites, see xref:af-get-started.adoc[].

== Deploy Your Agent Network

Let MuleSoft Dev Agent help you deploy your agent network instance. Just click the agent icon image:af-acb-dev-agent-icon.png["MuleSoft Dev Agent icon"] in the Anypoint Code Builder activity bar and tell the agent that you want to deploy your agent network. MuleSoft Dev Agent does the rest.  For more information about MuleSoft Dev Agent, see link:https://docs.mulesoft.com/anypoint-code-builder/api-ai-create-spec[Creating API Specs with AI].

**Suggested Prompts**

* Deploy my agent network project to the production environment.
* Deploy the hello-world-network project to staging.
* Deploy agent network project at /path/to/project to dev environment with specific gateways.
* Deploy my agent network to CloudHub 2.0.

If you don't want to use MuleSoft Dev Agent, deploy your agent network instance using these steps.

. In your Anypoint Code Builder project, in the *EXPLORER* bar, right-click a project file and select **Deploy Agent Network**. Or, run the command **MuleSoft: Deploy Agent Network** in the Command Palette.

. If you're not logged in already, log in to your Anypoint Platform account.

. In Deploy Agent Network, specify the environment, target space, gateways, and other deployment information.

. Select **Deploy**.

. Your agent network instance is deployed and ready to be tested.

Next, discover your agent network assets in Agents & Tools in Exchange, apply a governance policy, or monitor your agent network activity in Anypoint Monitoring.
