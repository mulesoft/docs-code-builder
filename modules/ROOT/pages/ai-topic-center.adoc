= Topic Center Overview

Enable API specifications for Topics. Topics are a bundle of actions and set of intructions Agents use to complete tasks. Agents are reusable across any set of topics. 

Agents can initiate and complete a sequence of tasks, search and summarize data, and take action in various systems. Agents have a role, access to content, and a set of actions they can take to complete a given task. 

MuleSoft’s API-led connectivity provides a framework for Agents to take action not only within Salesforce, but also across third-party systems like SAP, NetSuite, and so on.

Developers can create instructions for an Agent on the way to use an API, and automatically transforming the API operations to invocable-action based Agent actions, Topics enable Agents to use (and understand) APIs.
