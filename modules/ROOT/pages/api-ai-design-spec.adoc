= Designing API Specs with AI
:page-deployment-options: cloud-ide, desktop-ide

Simplify your API designs by generating API specifications with AI. Use natural language prompts in MuleSoft Dev Assistant to build APIs. The embedded MCP client powers these capabilities and is at the core of API spec generation in Anypoint Code Builder.

NOTE: AI-powered API specification generation is available on US, EU, Canada, and Japan cloud hosts.

== Trust Layer

The Dev Assistant flow bridges Anypoint Platform and the underlying large language models (LLMs):

image::acb-dev-assistant-trust-layer.png["Flow depicting how Dev Assistant interacts with the embedded MCP client"]

[calloutlist]
. The Anypoint Code Builder user creates a prompt based on their use case and submits it through Dev Assistant.  
. To minimize inaccurate responses (the AI "hallucination" effect), prompts are grounded with MuleSoft proprietary data and user context.
. Data is processed through the embedded MCP client, which manages secure communication with the LLM.
. To keep your data secure, all data remains within the Salesforce Shared Trust Boundary.  
. After the LLM generates a response, the content is returned through the secure pathway.
. MuleSoft validates the generated output to ensure that the specification works within the MuleSoft ecosystem. 
. Anypoint Code Builder displays the validated response in the IDE.

[IMPORTANT]
AI features can produce inaccurate or harmful responses. Review all generated output for accuracy and safety before applying it in production. You assume responsibility for the generated content when making business decisions.
