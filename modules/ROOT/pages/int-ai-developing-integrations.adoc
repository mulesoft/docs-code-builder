= Developing Integrations with MuleSoft Dev Assistant
:page-deployment-options: cloud-ide, desktop-ide

To jumpstart your integration development, use natural language input in MuleSoft Dev Assistant to generate flows for you. Dev Assistant runs on the A4D extension pack and an embedded MCP client, so you don’t need a Cursor subscription or any external LLM integration. All usage is billed through Einstein Requests.

This feature provides stateless AI interactions. Conversation history is not stored, and each prompt is processed independently.

[IMPORTANT]
Generative AI can produce inaccurate or harmful responses. Always review generated content for accuracy and safety before applying it in production. You assume responsibility for the output when making business decisions.

== Prerequisites

* Install Node.js version 20 (v20.19.4).  
For more information, see https://nodejs.org/en/download[Download Node.js].  
* Anypoint Code Builder must be running Mule runtime 4.9.6 or later and Java 17 for MCP servers.

== How It Works

1. You describe what you want to build using natural language prompts in Dev Assistant.  
2. The embedded MCP client securely processes your request and generates integration flows.  
3. MuleSoft validates the output to ensure the generated flow works within the MuleSoft ecosystem.
