= MuleSoft Vibes Learning Map for Anypoint Code Builder
:page-deployment-options: cloud-ide, desktop-ide

Follow the jobs below to open the topics that match what you need to accomplish next, from first-time setup through API design, integrations, agent networks, asset discovery, and production rollout.
