= MuleSoft Vibes for Anypoint Code Builder
:page-article-style: learning-map

MuleSoft Vibes is the natural-language assistant in Anypoint Code Builder for API specifications, integrations, and related tasks through optional MCP servers. Use this map to open MuleSoft Vibes topics in the order that matches your goal, from first launch through customization, generation, and troubleshooting.

The end-to-end journey for MuleSoft Vibes consists of various tasks, each with links to relevant content to assist you in completing them.
