= Creating Integrations with MuleSoft Dev Agent
:page-deployment-options: cloud-ide, desktop-ide
:page-aliases: int-ai-enable-einstein.adoc

The MuleSoft Dev Agent feature in Anypoint Code Builder transforms your natural language input into a flow that contains the connector operations and processors, in the correct order, to accomplish the specified task. 

For example, if you want to create a flow that reads contacts from Salesforce in JSON format, enter a prompt describing that task. Dev Agent then generates the connector operations and processors to execute the task, such as Listener, Query, Transformer, and Logger. 

Unlike previous versions of this feature, interactions are stateless: each prompt is processed independently, and the generated content is written directly into your project files when permissions are granted.

[[before-you-begin]]
== Before You Begin

Before you start creating your integration:

* xref:start-acb.adoc[Set up and access the web or desktop IDE].
* Ensure that you have the xref:start-configure-permissions.adoc#permissions[required Anypoint Code Builder permissions].
* Install Node.js version 20 (v20.19.4).  
For more information, see https://nodejs.org/en/download[Download Node.js].

[[access-dev-agent]]
== Access Dev Agent

There are two ways to open MuleSoft Dev Agent:

* When you create a new integration project, click a card in the flow canvas. For example, the *Build a Flow with AI* card.
* Click the Dev Agent icon in the toolbar.

[[craft-ai-prompt]]
== Write Your Prompt

Before you create a flow, define what you want to achieve with the flow, for example, optimizing a business process. In the Dev Agent panel, enter your prompt using natural language. The clearer and more specific your prompt, the more accurate the generated flow. 

Best practices for prompts:

* Be clear and precise.  
* Include triggering events (for example, sending an email when a new case is created).  
* Emphasize key MuleSoft components and connector operations (for example, HTTP Connector *Listener* and Email Connector *Send*).  
* Specify the data objects (for example, *Salesforce Account object*).  
* Review your prompt before submitting it.  

After Dev Agent generates the initial flow, the code is written directly into your project. You can further customize it to fit your requirements.

For examples of prompts and generated flows, see xref:int-ai-gen-flow-examples.adoc[].

[[agent-settings]]
== Configure Dev Agent Settings

Dev Agent can either request approval before writing into your project files, or apply edits automatically if *Auto-approve* is enabled.  

You can configure:  

* **Read project files** – Allow Dev Agent to read all files in the project.  
* **Edit project files** – Allow Dev Agent to write changes directly into your project.  
* **Auto-approve** – Bypass approval prompts and apply edits automatically.  

These options are available in the Dev Agent settings panel.

[[extend-dev-agent]]
== Extend Dev Agent with MCP, Rules, and Workflows

* The MuleSoft MCP server comes embedded in Dev Agent, providing built-in tools for tasks such as listing or deploying applications.  
* You can add custom MCP servers from Marketplace or by configuring a remote server.  
* Define *rules* to guide how Dev Agent generates flows according to your organization’s standards.  
* Create *workflows* to automate multi-step actions, which can be triggered through slash commands in the panel.  

[[complete-gen-flow]]
== Complete Your Flow

After Dev Agent builds the flow, complete the configuration as needed.  

Components that require further configuration display the error icon.  
Select the component in the canvas to determine where the error is. Anypoint Code Builder highlights the location of the error within the configuration XML.
