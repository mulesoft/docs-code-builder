= Creating Integrations with MuleSoft Dev Assistant
:page-deployment-options: cloud-ide, desktop-ide
:page-aliases: int-ai-enable-einstein.adoc

The MuleSoft Dev Assistant feature in Anypoint Code Builder transforms your natural language input, which describes your business logic, into a flow that contains the connector operations and processors, in the correct order, to accomplish the specified task. 

For example, if you want to create a flow that reads contacts from Salesforce in JSON format, enter a prompt describing that task. Dev Assistant then generates a series of connector operations and processors to execute the task, such as Listener, Query, Transformer, and Logger. 

Dev Assistant generates a flow, which you can then further configure to suit your specific needs. Unlike previous versions of this feature, interactions are stateless: there is no conversation history, and each prompt is processed independently. 

[[before-you-begin]]
== Before You Begin

Before you start creating your integration:

* xref:start-acb.adoc[Set up and access the web or desktop IDE].
* Ensure that you have the xref:start-configure-permissions.adoc#permissions[required Anypoint Code Builder permissions].
* Install Node.js version 20 (v20.19.4).  
For more information, see https://nodejs.org/en/download[Download Node.js].

[[access-dev-assistant]]
== Access Dev Assistant

There are two ways to open MuleSoft Dev Assistant:

* When you create a new integration project, click a card in the flow canvas. For example, the *Build a Flow with AI* card.
* Click the Dev Assistant icon in the toolbar.

[[craft-ai-prompt]]
== Write Your Prompt

Before you create a flow, define what you want to achieve with the flow, for example, optimizing a business process. In the Dev Assistant panel, enter your prompt using natural language. The clearer and more specific your prompt, the more accurate the generated flow. 

Best practices for prompts:

* Be clear and precise.  
* Include triggering events (for example, sending an email when a new case is created).  
* Emphasize key MuleSoft components and connector operations (for example, HTTP Connector *Listener* and Email Connector *Send*).  
* Specify the data objects (for example, *Salesforce Account object*).  
* Review your prompt before submitting it.  

After Dev Assistant generates the initial flow, you can further customize it to fit your requirements.

For examples of prompts and generated flows, see xref:int-ai-gen-flow-examples.adoc[].

[[add-gen-flow]]
== Add a Flow to Your Project

To add a flow using MuleSoft Dev Assistant:

. In the *Build your Enterprise with AI* card, click *Use Dev Assistant*.  
. Enter a prompt to create the initial flow for your task.  
+
Optionally, click an example to get started.  
+
When your flow is ready, the code and a description of the components in the flow appear in the Dev Assistant panel.  
. Inspect the generated code. If you're satisfied, click the insert code icon to add the code to your flow.  
. If you aren't satisfied with the generated flow, try rewording your prompt and submitting it again.  

[[customize-gen-flow]]
== Complete Your Flow

After Dev Assistant builds the flow, complete the configuration as needed.  

. After you inspect the code for your generated flow, you can either copy it into your clipboard or insert it with a single click using the *Insert* action.  
+
After you insert the code, the initial flow is built and the visual representation of the flow is shown in the flow canvas next to the XML code tab.  
+
Components that require further configuration display the error icon.  
. Select the component in the canvas to determine where the error is.  
+
Anypoint Code Builder highlights the location of the error within the configuration XML.
