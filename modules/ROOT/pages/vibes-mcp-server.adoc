= Configuring an MCP Server
:page-aliases: a4d-mcp-server.adoc

Add and manage MCP servers in Anypoint Code Builder to extend MuleSoft Vibes with tools for API design, integrations, governance, and agent networks. 

== Use MuleSoft MCP Servers

MuleSoft MCP Servers implement the Model Context Protocol (MCP) so AI assistants in your IDE can work with MuleSoft products and services. MuleSoft DX MCP Server supports API design, application deployment, and asset management. MuleSoft Platform MCP Server supports service discovery, policy enforcement, and traffic monitoring across your organization.

MuleSoft MCP Servers are available in Anypoint Code Builder and are also supported when you use the Anypoint Extension Pack in compatible IDEs such as VS Code, Cursor, or Windsurf. 

For more information about MuleSoft MCP Servers, see: xref:mulesoft-mcp-server::index.adoc[MuleSoft MCP Servers].

[[add-and-manage-custom-mcp-servers]]
== Add and Manage Custom MCP Servers

From the MuleSoft Vibes panel, you can add your own MCP server or manage connected MCP servers through the MCP Server settings.

[[open-mcp-server-settings]]
== Open MCP Server Settings

. Open the MuleSoft Vibes panel in Anypoint Code Builder.
. Select *Manage MCP Servers*.
+
NOTE: From this view, you can enable or disable MCP servers that have been installed. MuleSoft MCP Servers comes pre-installed with MuleSoft Vibes.
. Select the gear icon to open the full MCP Server settings.

This opens the MCP Servers UI with three tabs:

* *Marketplace*
* *Remote Servers*
* *Installed*

With these views, you can install new MCP servers, connect to remote MCP servers, and manage existing MCP servers.

== Add an MCP Server

You can add a custom MCP server by installing the server from the Marketplace, adding a remote MCP server, or manually editing the configuration file.


=== Install From Marketplace

. In MCP Server settings, select the *Marketplace* tab.
. Browse the available MCP servers or filter by category.
. Click *Install* to add the selected MCP server to your environment.
+
NOTE: Marketplace servers include community-provided MCP servers. Not all servers are supported by Salesforce.

=== Add a Remote MCP Server

. Select the *Remote Servers* tab.
. Enter a *Server Name* and a *Service URL* for the remote MCP server.
. Click *Add Server* to connect to the remote instance.
. (Optional) Select *Edit Configuration* to manually configure the MCP server by updating the `a4d_mcp_settings.json` file.

=== Manually Configure the JSON File

If needed, you can configure MCP servers directly by editing the `a4d_mcp_settings.json` file:

. From the *Remote Servers* tab, select *Edit Configuration*.
. Update fields such as server names, URLs, and additional settings.
. Save your changes to apply the configuration.


== Manage Installed MCP Servers

Once an MCP server has been installed, you can manage it from the *Installed* tab.


== Turn Servers On and Off

. Select the *Installed* tab.
. Toggle each MCP server on or off.
. To restart a server, select *Restart Server* from its configuration panel.

== Manage Tools for an MCP Server

Each MCP server provides a set of tools that MuleSoft Vibes can use. The following steps show you how to work with an MCP server:

. In the *Installed* tab, select a server to expand its details.
. View the list of available tools for that server.
. To auto-approve an individual tool, check the *Auto-approve* box next to that tool.
+
NOTE: Auto-approval for tools is available only if Auto-approve has been enabled in MuleSoft Vibes settings.
. To auto-approve all tools from a server, scroll to the bottom of the list and enable *Auto-approve all tools*.

== Configure Request Timeout

Follow these steps to configure how long MuleSoft Vibes waits for a response from an MCP server:

. In the server details panel, locate *Request Timeout*.
. Select a timeout value.

== Delete an MCP Server

To remove an MCP server:

. Open the server's configuration panel from the *Installed* tab.
. Scroll to the bottom of the tools list.
. Select *Delete Server*.
. Confirm the deletion.

[NOTE]
You can delete custom MCP servers that you add. The MuleSoft MCP Server is pre-installed with MuleSoft Vibes and can be turned on or off, but it can't be removed.

Tool availability, behavior, and stability may vary depending on the MCP server version and configuration, as well as whether the server is community-provided or supported by Salesforce.
