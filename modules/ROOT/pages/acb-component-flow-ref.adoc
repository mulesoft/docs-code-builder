== Navigate to the referenced flow
You can open the flow that a Flow Reference component points to directly from the canvas, without switching views manually.
To view the referenced flow:

. Right-click the Flow Reference component in the canvas.
. Select *Go to Flow* from the context menu. Or, press Ctrl+Alt+g (Windows) or Cmd+Option+g (macOS) to open the flow.

Anypoint Code Builder opens the target flow in the appropriate canvas:
* In application flows, the referenced flow opens in the flow canvas.
* In MUnit test flows, the referenced flow opens in the MUnit canvas if applicable.

This helps you trace and manage flow logic across modular designs, whether you're building or testing your application.
