= Creating an API Specification for Agent Actions and Topics

Design and configure your API specs with agent usage in mind. 

== Before You Begin

API projects are automatically enabled for for agent actions and topics as long as:

* There is xref:access-management::trusted-salesforce-org.adoc[a tenant relationship] established between your Anypoint Platform organization and a trusted Salesforce organization that has Agent entitlements. 
* xref:access-management::enabling-api-catalog.adoc[API Catalog is enabled] for the connected Salesforce organization.
